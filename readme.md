# 🚗 BMW Showcase Website

A modern, interactive BMW car showcase website built using **HTML, CSS, JavaScript, and Node.js**.  
Users can browse BMW models, view car images, and explore detailed specifications like engine, power, mileage, and price.

---

## ✨ Features

✅ Interactive BMW car gallery  
✅ Click on any car to view detailed specifications  
✅ Responsive design (mobile + desktop)  
✅ Smooth animations and hover effects  
✅ Backend API using Node.js  
✅ JSON-based car data (no database required)  
✅ Lightweight and fast
